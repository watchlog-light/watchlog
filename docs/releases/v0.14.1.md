# WatchLog 0.14.1: What changed, on real data

Fixes found on the live demo once 0.14.0 was running there.

## Fixes

- **Monitored applications by name:** the live map and the last 7 days' cards showed a
  PostgreSQL, MySQL or MongoDB service by its id. They now show its name, as the list does.
- **WatchLog's own changes stay hidden with its parts:** with "Hide WatchLog's own parts" on,
  WatchLog's own updates (its rollouts, image changes and container re-creates, and restarts
  of the agent's services) no longer appear on the chart, under "Changed around then", or as
  a likely cause.
- **A readable chart in a busy place:** a cluster with a job every 10 minutes and scaling every
  15 put dozens of overlapping labels on the chart. Labels now go only where they fit,
  deployments and server changes first; the other changes are unlabelled lines, and each is
  still listed under "Changed around then".
- **One learning count:** the map's footer gives the same number of series still learning as
  the line above the page.

## Upgrading

No manual steps and no migration. Agents need no update.
