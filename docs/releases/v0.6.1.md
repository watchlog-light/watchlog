# WatchLog 0.6.1

A fix from the first hour of WatchLog Cloud.

## Fixed

- **Cloud: Settings › General loads.** It asked for the server's public address, which in Cloud belongs to the operator (the API answers 404), so the tab said "Could not load the settings." The tab now shows the system namespaces and who may read logs, read-only, as in Cloud they are the operator's too; saving them no longer fails.

Self-hosted installations (Community) see no change: the public address and both settings stay editable for owners and admins.

## Upgrading

No manual steps, and nothing changes for Community, so upgrading is optional there. Kubernetes: `helm upgrade … --version 0.6.1 --reuse-values`. Docker: set `WATCHLOG_VERSION=0.6.1`, then `docker compose pull && docker compose up -d`.
