# WatchLog 0.8.2

A small change to WatchLog Cloud's sidebar: the Pro sections now say so.

## Changed

- **A "Pro" chip in the sidebar.** On Cloud, What changed has a "Pro" chip next to it, so a Free org can see it's a Pro section before opening it. When the sidebar is collapsed, the tooltip reads "What changed · Pro". This applies to Kubernetes clusters and Docker fleets alike.

Community installations have no plans and see no change.

## Upgrading

No manual steps and no migration. Agents don't change. Kubernetes: `helm upgrade … --version 0.8.2 --reuse-values`. Docker: set `WATCHLOG_VERSION=0.8.2`, then `docker compose pull && docker compose up -d`.
