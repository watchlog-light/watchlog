# WatchLog 0.11.1: update the agents from the panel

WatchLog now tells you when an agent is older than itself, and hands you the command that
updates it, filled in.

## What's new

- **Update the agents:** a server's page shows "Agent 0.10.1 · update to 0.11.1"; a fleet's
  Servers and a cluster's Nodes say "4 of 6 servers run an older agent"; each cluster's
  Settings has an Agents section; All clusters' Housekeeping links each one. All open one
  dialog with the right command: the install script's `--upgrade`, the deb or rpm of this
  release, the Docker agent re-created with the token it already has, or `helm upgrade` of the
  chart the cluster runs. A fleet gets an SSH loop over its out-of-date servers.
- **The agent says how it was installed** (script, deb, rpm or Docker), so the dialog shows
  the one command that fits.
- **API and MCP:** `GET /api/v1/clusters/{id}/agents`; `updateAvailable` on nodes, servers and
  clusters.

## Fixes

- **All clusters and fleets:** the status sentence counts every cluster and fleet that isn't
  healthy, with "3 critical · 2 warning" under it; Needs attention lists exactly what each
  cluster's own Overview lists; Pro orgs see the plain name in the sidebar and the switcher.
- A backend test that depended on a few seconds of timing.

## Upgrading

Update the backend first, then the agents from the panel. No manual steps.
