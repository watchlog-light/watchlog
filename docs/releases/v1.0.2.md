# WatchLog 1.0.2: edit, test and undo on the network pages

A patch release for Network devices (Enterprise and Cloud Pro), after a customer's report: a
credential profile made with a mistake could be neither corrected nor removed.

## What's changed

- **A credential profile is edited and deleted from its card**
  ([docs](https://github.com/watchlog-light/watchlog/blob/v1.0.2/docs/site/network.md#changing-testing-and-deleting-a-profile),
  ADR-241). On Network → Add devices, step 2, each profile has **Edit** and **Delete**. Edit
  opens the profile's form filled in, without its secrets: leave one empty to keep it. The
  protocol can't change. Delete asks first; a profile that devices use lists them and offers to
  move them to another profile of the same protocol, and then it can be deleted. Owners and
  Admins; a Viewer sees the cards with the controls locked.
- **Test against an address.** The same form reads one device with the values as typed, before
  anything is saved, through the poller you choose, and says what happened: it answered (its
  name and model), it refused the user or the key, nothing answered, or the certificate isn't
  the pinned one. Read-only, on a Kubernetes cluster's collector or a fleet server's.
- **A device's address, pause and return.** A device's page corrects an address typed wrong,
  pauses polling and resumes it, and says what removing does: the history stays until retention
  ends, and adding the same address again brings the same device back with it.
- **An accepted certificate can be undone** by an Owner, on the device's page.
- **A poller's devices move together.** Step 1 says how many devices each poller reads, and
  moves all of them to another poller when a server stops being a good one.
- **The audit trail has all of it**: profiles made, changed and deleted, devices added, changed,
  moved and removed, certificates accepted and undone, what a UPS powers. Never a secret.

## What's fixed

- The tabs row of the network pages showed a stray scroll control at its right edge on a narrow
  window. It now scrolls sideways without one.
- "How to make this read-only user on the device" reads as a help section: folded, with a
  chevron and the protocols it is about.

## Upgrading

Nothing to do: two small migrations run on their own. Agents need no update. A collector from
1.0.2 answers a profile's test in a few seconds; an older collector keeps working and answers
with its next round (up to a minute and a half), and can't test a recorder profile until it is
updated.
