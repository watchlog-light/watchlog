# WatchLog 0.2.0

Ask your AI assistant what's wrong with your cluster. WatchLog 0.2 adds personal API tokens, a documented REST API and a built-in MCP server. Claude Code, Claude Desktop, Cursor or your own scripts can read your Kubernetes clusters and Docker hosts, and they can't change anything.

Try it on the live demo, with its public token:

```bash
claude mcp add --transport http watchlog-demo https://demo.watchlog.io/mcp \
  --header "Authorization: Bearer wl_pat_demoWafe1IZZ5LgmkIMrbhhfs932B8pd75Lr8P4fomh"
```

## What's new

- **Ask your cluster (MCP)** (ADR-127 to ADR-129): `<your address>/mcp`, for Claude Code, Claude Desktop (through `mcp-remote`), Cursor and any MCP client. It speaks the 2026-07-28 protocol and the 2025 versions.
  - **11 read-only tools:** problems, alerts and why one fired, workloads and Compose services, pods and containers, nodes and Docker hosts, the service map, events, recent changes, and metrics. Each answers in the right words for a Kubernetes cluster or a Docker fleet.
  - **Two prompts:** "investigate what's wrong" and "why is it crashing".
  - **Bounded answers:** at most 16 KB, with a hint when an answer is cut.
  - **Cluster text is data.** Names and messages from your cluster come back only in their own fields, cleaned, as a defence against prompt injection.
  - Guide: [Ask your cluster](https://github.com/watchlog-light/watchlog/blob/v0.2.0/docs/site/mcp.md).
- **Personal API tokens** (ADR-125), in **Settings → API tokens**:
  - **Scope and expiry:** read only, expiring after 30 days, 90 days, a year or never, with an email 7 days before.
  - **Revoking** works at once.
  - **Each token's history:** created, first use, use from a new address, expired, revoked.
  - **MCP activity:** the last 50 tool calls, never their answers.
  - **Limits:** 300 requests and 60 tool calls a minute per token.
- **A public REST API** (ADR-126):
  - 24 documented routes for both kinds of cluster, stable under `/api/v1`. Additions can come in any release; a breaking change needs `/api/v2` or two minor versions of deprecation.
  - `/api/v1/openapi.json` lists them.
  - Guide: [REST API](https://github.com/watchlog-light/watchlog/blob/v0.2.0/docs/site/api.md).
- **The live demo** gets a public MCP token (ADR-130), limited to 30 tool calls a minute per visitor and 600 in total.

## Security

- **What tokens never get:** Secrets, environment values, payloads, alert channel targets, email and Telegram settings, other tokens, and the error text of failed alert deliveries.
- **What tokens can read:** only routes tagged public. A new route stays closed to tokens until it is tagged.
- **Demo mode** no longer shows kernel versions. A demo's nodes may share their host's kernel.

## Upgrading

Upgrades need no manual steps: the new tables are created by migrations, and every new chart value is optional (`mcp.enabled` defaults to `true`; the MCP server needs a token anyway). To turn MCP off, set `mcp.enabled: false` (Helm) or `WATCHLOG_MCP_ENABLED=false` (Compose).

For MCP clients, WatchLog must be reachable at its public address (Settings → General). The web container forwards `/mcp` to the backend. An ingress or reverse proxy in front only needs to pass `/mcp` on like every other path; streamed answers flow best with response buffering off.

## Known limits

- MCP uses bearer tokens; OAuth (native "custom connectors" in Claude's apps) comes later.
- One cluster per installation (Community). English only.
