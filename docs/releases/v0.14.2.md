# WatchLog 0.14.2: What changed, two more fixes

## Fixes

- **"checked 12 s ago" means it:** the live line now gives the time WatchLog last checked. It
  used to give the minute it had scored, which is a minute or two earlier to let data settle,
  so right after a check it could say "checked 140 s ago".
- **Chart labels no longer run into each other:** a change's label now goes only where its
  text fits, including near the right end, where labels hang to the left of their line.

## Upgrading

No manual steps and no migration. Agents need no update.
