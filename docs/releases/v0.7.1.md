# WatchLog 0.7.1

A fix for Egress watch in the public demo.

## Fixed

- **Demo: Egress watch asked for more than the demo answers.** The demo shows at most the last 24 hours, but the Egress page offered 7 and 30 days ("Couldn't load the destinations"), and "Talks to the internet" on workload, pod, container and Compose service pages, and the card on an egress alert, always read 30 days, so they failed there too. In the demo, the page now offers 1 hour and 24 hours (a 7- or 30-day link opens 24 hours), and the cards read the last day. Kubernetes and Docker alike.

Installations that are not the demo (Community and Cloud) see no change.

## Upgrading

No manual steps, and nothing changes outside the demo, so upgrading is optional. Kubernetes: `helm upgrade … --version 0.7.1 --reuse-values`. Docker: set `WATCHLOG_VERSION=0.7.1`, then `docker compose pull && docker compose up -d`.
