# WatchLog 0.6.2

A fix from the first day of WatchLog Cloud.

## Fixed

- **Cloud: one account per email address.** "Continue with GitHub" or "Continue with Google" with an address that already had an account made a second, empty account. Now it says the address has an account: sign in the way you signed up, then add GitHub or Google in Settings › Security, after which either one opens the same account. Nothing is ever linked by matching addresses (ADR-183).

Self-hosted installations (Community) see no change: they have no sign-up and no GitHub or Google sign-in.

## Upgrading

No manual steps, and nothing changes for Community, so upgrading is optional there. Kubernetes: `helm upgrade … --version 0.6.2 --reuse-values`. Docker: set `WATCHLOG_VERSION=0.6.2`, then `docker compose pull && docker compose up -d`.
