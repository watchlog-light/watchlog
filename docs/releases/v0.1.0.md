# WatchLog 0.1.0

The first public release of WatchLog Community: open-source monitoring for Kubernetes and Docker, with one agent.

## Highlights

- **Kubernetes:** one Helm chart installs the backend, the web UI and the agents. Cluster overview, nodes, workloads, pods with restart and OOM reasons, events, and Kubernetes objects from a cluster-agent that watches the API, so nodes never need API access.
- **Docker hosts:** one `docker run` per host. Hosts, containers, health checks and why a container stopped.
- **Service map from eBPF:** who connects to whom, with connection rates, failures, connect latency, bytes and DNS errors. No code changes and no sidecars. External dependencies are named by DNS. It needs Linux 5.8+ with BTF; other nodes show topology from Services and say why.
- **Alerts that work on day one:** default rules for crash loops, OOM kills, node pressure, failing connections and more, sent to Slack, Telegram, email or webhooks.
- **Read-only, least privilege:** the node agent reads `/proc`, `/sys` and its kubelet, and loads eBPF programs with only `BPF` and `PERFMON`. It never reads Secrets, ConfigMap data, environment values or request payloads. See [security](../site/security.md).
- **Self-hosted and free** for one cluster under AGPL-3.0.

## Upgrading

Upgrades need no manual steps: `helm upgrade --reuse-values` from any earlier chart turns network flows on, and a Docker agent is upgraded by re-running the install command.
